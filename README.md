## Prerequisites

Ensure that you have the following versions installed:

- **Flutter**: `3.19.5`
- **Dart**: `3.3.3`

## Installation

1. **Clone the repo**

   ```bash
   git clone https://github.com/josephchay/smart-fridge.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd application/
   ```

3. **Connect to a mobile device** via USB cable or Bluetooth with **Developer Debugging Mode** enabled.

4. **Install dependencies**

   ```bash
   flutter pub get
   ```

5. **Run the app**

   ```bash
   flutter run
   ```

## Running Tests

Run automated tests for this system with:

```bash
flutter test
```
